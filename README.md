# 回廊 · The Silent Corridor

一款原创浏览器等距空间解谜游戏。Vite + TypeScript + Three.js，三个章节，中文界面，支持鼠标与触屏。

## GitHub 发布

- 源码仓库：https://github.com/0xAliya/huilang2
- 在线游戏：https://0xAliya.github.io/huilang2/
- `main` 保存源码；`.github/workflows/deploy.yml` 在推送后安装依赖、验证关卡并构建，将静态产物发布到 `gh-page` 分支。自动发布需要仓库具备可用的 GitHub Actions 运行额度与权限。
- GitHub Pages 的发布源设置为 `gh-page` 分支的根目录。该分支由自动化维护，每次发布替换构建产物。
- Vite 的 `base` 为 `/huilang2/`，适配 GitHub 项目站点子路径。
- 也可以运行 `npm run deploy` 手动构建并更新 `gh-page`。需要 Git 已配置仓库写入权限。

## 启动

```bash
npm install
npm run dev
```

打开终端输出的开发预览地址。服务器启用了 `strictPort`；端口被占用时，可通过 `-- --port <端口>` 指定其他空闲端口。

```bash
npm test             # 纯逻辑与关卡求解
npm run typecheck    # tsc --noEmit
npm run build        # 类型检查与生产构建，输出 dist/
npm run test:e2e     # 先启动开发服务器；需要 Google Chrome
```

浏览器测试使用独立临时浏览器环境，分别以 1280×800 和 390×844 运行，截图写入 `artifacts/`。若更换开发端口，请同步修改 `playwright.config.ts` 中的 `baseURL`。

## 怎么玩

- 点击带小菱形镶嵌的石阶，旅人会自动寻找当前可达的路线。
- 点击或横向拖动金色转轮，每次旋转 90°；也可使用底部同名机关按钮。
- 第三章可以拖动渡台上的金色把手或底部滑杆，松开后吸附停靠。底部渡台按钮也可以切换两端。
- 站在机关上的旅人会随机关一起移动。行走、旋转和吸附期间会锁住其他操作。
- 点击右上角声音按钮静音；声音在首次点击或键盘操作后启动。
- 「一点灵感」根据当前节点与机关状态给出下一步提示。左上角可以重置本关或返回选关。
- 到达光门后自动解锁并进入下一章；三章结束后显示通关页。

### 最少操作解法

| 章节 | 机制 | 最少次数 | 解法 |
| --- | --- | --- | --- |
| 01 初阶 | 旋转桥 | 1 | 回转桥转一次，点击光门前的石阶。 |
| 02 错位 | 转柱与视错觉通路 | 2 | 先走上金色桥端，转柱转两次，再走到光门。 |
| 03 潮汐 | 双生滑台、转柱、视错觉 | 4 | 走上去程渡台，滑到右端；走上转柱，转两次；走过幻径到返程渡台，滑回左端；走到光门。 |

「次数」只计机关操作，不计行走。滑台两个平台一起移动，但行走图并不把它们直接连通。

## 工程

```text
src/
  engine/     类型、条件行走图、BFS、0–1 BFS 求解器、格子变换、正交投影
  levels/     三个独立 TypeScript 关卡数据
  render/     Three.js 建筑、相机、角色、动画、射线拾取、拖动
  ui/         中文 HTML 界面、自适应样式
  audio/      Web Audio 合成音
  main.ts     游戏状态与异步操作调度
tests/
  engine.test.ts
  browser/journey.spec.ts
artifacts/    桌面、手机及机关状态截图
```

`engine/` 不依赖 Three.js。方块顶面是行走节点，所有关卡坐标为整数格；条件边只在相应机关状态下开放。机关动画完成后才提交新的状态。角色节点 ID 在搭乘期间保持不变，其坐标由机关变换计算。

求解器搜索「角色节点 × 全部机关状态」。行走边权为 0，机关操作边权为 1，通过 0–1 BFS 找到最少机关操作解。浏览器测试读取求解器输出，使用实际鼠标点击或触屏点击执行解法，不通过诊断接口修改游戏状态。

固定相机沿 `(1, 1, 1)` 方向观察。纯逻辑投影：

```text
screenX = (x - z) / √2
screenY = (2y - x - z) / √6
一格在屏幕上的长度 = √(2/3)
```

幻径将目标映射到与起点相邻的虚拟格，角色走到边中点时沿视线切换深度，投影位置保持连续。相机根据建筑在所有机关状态下的包围盒角点取景，兼容横屏与竖屏。

## 美术、音效与存档

建筑、拱门、树木、小人、粒子均为程序化几何，没有使用现成游戏素材。暖粉、青绿、暮紫对应三个章节；使用环境光与方向光，不开启实时阴影。字体使用系统宋体与界面字体，无需加载在线字体。

脚步、机关五声音阶、不可达提示与通关和弦都由 Web Audio 即时合成。没有后端或第三方数据请求。

存档使用 `localStorage`：

- `huilang:progress:v1`：已解锁章节与全通关标记。
- `huilang:muted`：静音偏好。

保存的是章节进度；重开章节会重置当前谜题。损坏或不可访问的存储会安全回退，仍可继续游戏。

## 验收范围

单元测试涵盖可达／不可达、条件边、旋转循环、锁定、滑台吸附、搭乘坐标、三个关卡的最优解、初始不可通关、整数格与空间无重叠，以及所有生效幻径的投影距离和深度切换连续性。浏览器测试涵盖完整三关流程、章节解锁、存档恢复、静音记忆、拖动吸附、操作锁定和重置。

本版面向支持 WebGL 2 与 Web Audio 的现代浏览器。已配置的浏览器验收为 Chrome；没有包含真机 Safari 兼容性结论。Three.js 为独立构建分块，开发诊断接口只在 Vite 开发模式提供。
